# Project Formation GTM

## Purpose

Help the PM shape launch and adoption decisions with the same rigor as product shaping.

Treat GTM as a set of testable bets tied to measurable outcomes.

## Conversational behavior

- Ask for evidence behind messaging choices.
- Force prioritization of audience segments.
- Keep GTM scope consistent with project appetite.
- Turn goals into measurable thresholds.

Challenge vanity metrics and replace them with behavior or business-impact metrics.

## Flow

1. Define primary segment and secondary segment.
2. Craft positioning:
   - who this is for
   - problem solved
   - why this approach now
3. Select launch channels by confidence and effort.
4. Define 2-4 launch bets with KPI thresholds.
5. Define failure signals and iteration triggers.

Use templates:

- `assets/gtm-plan-template.md`
- `assets/experiment-card-template.md`
- `assets/kpi-tree-template.md`

## Shape Up lens

- Treat launch as a bet, not a certainty.
- Keep first rollout narrow enough to learn fast.
- Make rollback or pause criteria explicit.

Constrain first launch to appetite and confidence; avoid broad rollout without early evidence.

## Exit gate

GTM is complete when:

- segment priority is explicit
- core message is validated against discovery pains
- KPI thresholds define success/failure
- next iteration path is clear if the first bet underperforms

Apply `assets/gtm-readiness-checklist.md` before moving to dossier.

# Routing Matrix

Use this matrix to select the next stage.

## Inputs

- Current stage
- Evidence quality
- Assumption risk
- Scope clarity
- Appetite clarity

## Decision Matrix

- Choose discovery when problem evidence is weak, user segment is unclear, or assumptions are mostly untested.
- Choose shaping when problem is credible and the challenge is deciding bounded solution direction.
- Choose roadmap when direction is shaped and the challenge is sequencing work under constraints.
- Choose GTM when execution path exists and the challenge is adoption and launch strategy.
- Choose dossier when all prior stages are coherent, justified, and confidence is medium/high.

## Confidence Rules

- Low confidence keeps the workflow in current stage.
- Medium confidence allows progression only if top risks have explicit controls.
- High confidence allows progression when skip-guard passes.

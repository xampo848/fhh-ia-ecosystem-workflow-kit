# Roadmap Readiness Checklist

## Checklist

- Initiative sequence is outcome-driven, not task-driven.
- Appetite and scope boundaries are explicit per phase.
- Dependencies are visible with mitigation.
- Confidence is stated for each phase.
- Review cadence is defined (weekly/biweekly/monthly).

## Verdict

- pass: proceed to GTM.
- hold: resolve highest-risk gap first.

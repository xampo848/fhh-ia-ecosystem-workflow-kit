# Ambiguity Question Ladder

Use this ladder when the PM's input is directionally useful but still ambiguous.

Apply one question at a time. Do not ask multiple ambiguity questions in the same turn.

## 1) Term ambiguity

- What does [term] mean operationally for this team?
- Which interpretation should we discard now?

## 2) Scope ambiguity

- What is explicitly in scope for this cycle?
- What is explicitly out of scope for this cycle?

## 3) Outcome ambiguity

- What measurable behavior change defines success?
- By when do we expect to observe that change?

## 4) Ownership ambiguity

- Who owns this decision now?
- Who can block this decision?

## 5) Risk ambiguity

- What assumption can invalidate this decision fastest?
- What evidence would change our mind?

## 6) Sequence ambiguity

- What must be true before phase 2 starts?
- Which dependency is critical path versus nice-to-have?

## 7) Decision closure check

- Is there any sentence here that two stakeholders would interpret differently?
- If yes, rewrite it in one unambiguous sentence before progressing.

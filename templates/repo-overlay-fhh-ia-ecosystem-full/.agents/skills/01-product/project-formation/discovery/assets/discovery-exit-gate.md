# Discovery Exit Gate

Discovery can close only if all conditions are met.

## Gate Conditions

- Target segment is explicitly defined.
- Problem is framed in user and business terms.
- At least one high-impact assumption is testable.
- Appetite hint is stated and justified.
- Major unknowns are visible and prioritized.

## Decision

- pass: move to shaping.
- hold: run one focused discovery loop for missing conditions.

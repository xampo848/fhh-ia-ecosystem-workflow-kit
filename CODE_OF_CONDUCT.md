# Code of Conduct

## Our standards

Participants are expected to be respectful, constructive, and professional.

Unacceptable behavior includes harassment, discrimination, personal attacks, doxxing, or abusive language.

## Enforcement

Maintainers may edit, remove, or reject contributions and discussions that violate this code.

Repeated or severe violations may result in temporary or permanent participation restrictions.

## Reporting

Report a violation privately to the maintainers through GitHub: use the
repository's private reporting form (**Security** tab → **Report a
vulnerability**,
<https://github.com/xampo848/fhh-ia-ecosystem-workflow-kit/security/advisories/new>)
and state that the report is a code of conduct matter. Do not report it in a
public issue. A report sent this way is visible only to the maintainers.
